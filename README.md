# 💖 موقع نفين

موقع رومانسي بـ React + Vite + Framer Motion.

## التشغيل
```bash
npm install
npm run dev
```

## الملفات اللي بتتحط في public/
- `public/images/photo1.jpg … photo4.jpg` — صور المعرض (4 صور)
- `public/images/profile.jpg` — صورة البروفايل (اختيارية)
- `public/video/our-video.mp4` — الفيديو
- `public/music/our-song.mp3` — الأغنية

## بيانات الموقع
- الباسورد: `src/components/PasswordGate.jsx`
- تاريخ العداد: `src/components/CounterSection.jsx` (5/10/2025)

## الرفع
```bash
npm run build
```
وارفع مجلد `dist/` على Netlify أو Vercel.
